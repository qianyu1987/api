CC Switch 配置教程

推荐一键导入

完成下面 3 步即可开始使用。API Key 只在创建或验证后显示，请不要发给他人。

1
下载并打开 CC Switch

使用上方 CC Switch 官方入口下载安装。首次打开后进入供应商或 Provider 管理页。

打开下载页
2
创建一个 API Key

进入 API Keys 页面，点击“新建 Key”。完整 Key 只显示一次；如果已创建，可通过“复制完整 Key”并验证当前密码后查看。

3
一键导入并测试

在 API Keys 列表点击“导入 CC Switch”，浏览器会打开 CC Switch 并自动带入地址、模型和 Key。回到 CC Switch 后保存 Provider，再发送一条测试消息。

一键导入失败时，手动填写这些内容
Provider 类型OpenAI Compatible
名称GPT TOKEN
API Base URL
--
API Key填写刚创建的完整 API Key
模型填写后台已启用的模型名，例如 gpt-6-astra 或 gpt-5.6-sol
请求格式OpenAI Chat Completions / Responses（按客户端支持选择）
测试失败怎么处理
  • 401 / Key 无效：确认复制的是完整 Key，且 Key 未撤销；必要时重新创建一个 Key。
  • 模型不存在：检查模型名称和后台启用列表，先用已启用的模型测试。
  • 余额不足：回到“充值与套餐”充值，到账后重新测试。
  • 连接超时：确认 Base URL 以 /v1 结尾，并检查网络后重试。
